기관별 진행상황, 요청·회신, 협의사항과 실증 현황을 하나의 공유DB에서 관리합니다.

답변 후 잠금소통 이력 보호
실증 4단계완료 인원만 입력

1. 기본 이용 흐름

로그인

관리자가 발급한 로그인 ID와 비밀번호를 사용합니다. 초기 비밀번호는 최초 로그인 후 변경합니다.

기관 진행현황 확인

상단 기관 탭을 이동하면 전체 기관을 조회할 수 있습니다. 자기 소속기관 항목만 수정할 수 있습니다.

요청·회신 및 협의

관련 진행항목을 연결해 요청 또는 협의사항을 등록합니다. 답변이 달린 원문은 수정·삭제할 수 없습니다.

실증 현황 확인

페이지 하단에서 실증기관별 목표 인원과 4단계 진행률을 한눈에 확인합니다.

3. 실증 현황 읽는 법

각 실증기관은 목표 인원을 하나 갖고, 사전설문·교육·사용·사후설문을 각각 전체 진척도의 25%로 계산합니다.

사전설문 25%교육 25%사용 25%사후설문 25%
예: 목표 40명, 사전설문 40명 / 교육 20명 / 사용 0명 / 사후설문 0명 → 전체 진척도 37.5%

책임기관 입력

책임기관은 각 단계에서 완료된 인원수만 입력합니다. 개인정보나 참여자 명단은 이 시스템에서 관리하지 않습니다.

4. 관리자

관리자 모드의 실증 관리에서 실증기관을 추가하고 기관명, 책임기관, 목표 인원, 연계 진행항목을 설정합니다. 운영 관리자 계정은 최대 2개입니다.

실증기관 추가→책임기관 지정→목표 인원 입력→연계 진행항목 체크→기관별 완료 인원 집계

비밀번호 원문은 DB에 저장하지 않습니다. 비밀번호를 잊은 경우 로그인 화면의 초기화 요청을 사용하고 관리자가 사용자 관리에서 재설정합니다.

5. 사례비

사례비 체크박스는 해당 실증기관의 사례비 지급 완료 여부를 별도로 기록합니다. 실증 진행률 계산에는 포함되지 않습니다.
