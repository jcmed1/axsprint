AX SPRINT CONTROL TOWER · INSTITUTION USER

기관 사용자 이용 매뉴얼

기관 담당자가 로그인 후 확인·수정할 수 있는 범위와 실제 입력 절차를 순서대로 설명합니다.

전체 조회모든 기관 현황
자기 기관 편집자기 데이터만
요청·회신기관 간 협업
실증 입력책임기관만

1. 최초 로그인

관리자가 전달한 접속주소 열기

대표 URL 또는 기관별 링크로 접속합니다.

로그인 ID·초기 비밀번호 입력

관리자가 발급한 정보를 사용합니다.

첫 로그인 후 비밀번호 변경

새 비밀번호를 2회 입력해 저장합니다. 이후부터 새 비밀번호를 사용합니다.

로그인 후 상단에 사용자명·소속기관이 표시됩니다. 소속기관이 잘못 표시되면 관리자에게 수정 요청하십시오.

2. 기관 화면 보는 법

상단 기관 선택에서 정션메드, 경복대학교, 돌봄과 미래, 에임랩을 모두 조회할 수 있습니다.

화면가능한 작업
자기 소속기관진행항목 추가·수정, 자기 요청/협의 작성, 자기 회신, 책임 실증기관 실적 입력
다른 기관조회만 가능. 수정·삭제 불가

첫 화면은 현재 주요 진행사항, 요청·회신, 협의사항, 전체 항목 카드, 실증 현황 순으로 확인합니다.

3. 진행항목 등록·수정

자기 기관 화면에서 + 진행항목

자기 기관의 진행사항을 새로 등록할 때 사용합니다.

항목명·일정·상태 입력

실제 운영 상황에 맞는 현재일정과 상태를 입력합니다.

완료기준 확인

완료로 처리하기 전에 완료기준이나 필요한 산출물이 충족되었는지 확인합니다.

다른 기관 진행항목은 수정할 수 없습니다. 전체 사업 기준일정·고유번호 등 관리영역은 관리자 권한이 우선합니다.

4. 고유번호와 관련 진행항목

진행항목에는 AX-0001 같은 표시용 고유번호가 붙을 수 있습니다. 요청이나 협의사항에 관련 진행항목을 선택하면 해당 번호가 태그로 표시됩니다.

태그를 누르면 연결된 진행항목으로 이동합니다. 고유번호가 관리자에 의해 변경되어도 내부 연결은 유지됩니다.

5. 요청 보내기

요청·회신 → 요청 보내기

자기 기관 화면에서 버튼을 누릅니다.

수신기관 선택

한 기관 또는 여러 기관을 동시에 선택할 수 있습니다.

제목·내용·회신 희망일 입력

받는 기관이 바로 처리할 수 있도록 요청내용을 구체적으로 작성합니다.

관련 진행항목 선택

요청이 특정 진행항목과 연관되면 반드시 연결합니다.

등록

보낸 요청에서 처리상태와 기관별 회신을 확인합니다.

상대 기관이 회신하기 전에는 자기 요청을 수정·삭제할 수 있습니다. 하나라도 회신이 달리면 원문은 자동 잠금됩니다.

6. 받은 요청에 회신하기

요청·회신 → 받은 요청

회신이 필요한 항목을 선택합니다.

요청 원문과 관련 진행항목 확인

내용과 회신기한을 확인합니다.

회신내용·회신일 입력

자기 기관 회신만 작성합니다.

회신 저장

저장 후 요청기관과 다른 관련기관이 내용을 조회할 수 있습니다.

자기 회신은 권한 범위 내에서 수정할 수 있습니다. 다른 기관 회신은 수정할 수 없습니다.

7. 협의사항 작성

공식 요청까지는 필요하지 않은 협의, 확인사항, 진행 중 의견은 협의사항으로 기록합니다.

협의사항 작성

제목과 본문을 입력합니다.

관련 진행항목 선택

연관 항목이 있으면 연결합니다.

답변 확인

다른 기관이 답변을 남기면 원문은 잠기며 이후 내용은 추가 답변으로 이어갑니다.

8. 실증 현황 입력

실증기관의 책임기관으로 지정된 경우에만 완료 인원과 사례비 상태를 수정할 수 있습니다.

사전설문 25%교육 25%사용 25%사후설문 25%
하단 실증 현황에서 기관 선택

자기 책임 실증기관을 클릭합니다.

목표 인원 확인

관리자가 정한 목표 인원을 기준으로 합니다.

단계별 완료 인원 입력

사전설문, 교육, 사용, 사후설문 각각 완료된 인원수를 입력합니다.

사례비 지급 완료 시 체크

사례비 체크는 적색으로 표시되며 실증 진척률에는 포함되지 않습니다.

개인별 이름이나 민감정보는 이 시스템에 입력하지 않습니다. 완료 인원 집계만 입력합니다.

9. 실증 진행률 계산

각 단계는 25%씩 반영됩니다. 단계 내 진행률은 완료 인원 ÷ 목표 인원으로 계산됩니다.

예: 목표 40명, 사전설문 40명, 교육 20명, 사용 0명, 사후설문 0명 → 25% + 12.5% = 37.5%.

네 단계가 모두 목표 인원에 도달하면 실증 완료 상태가 됩니다.

10. 비밀번호 변경·분실

본인이 변경할 때

상단 내 계정 → 새 비밀번호 입력 → 비밀번호 변경

비밀번호를 잊었을 때

로그인 화면의 비밀번호 초기화 요청

본인 로그인 ID를 입력합니다.

관리자에게 연락

관리자가 임시 비밀번호를 새로 설정합니다.

임시 비밀번호로 로그인

로그인 후 새 비밀번호로 다시 변경합니다.

11. 수정·삭제가 안 될 때 확인

상황이유
다른 기관 항목 수정 불가정상입니다. 다른 기관 데이터는 조회 전용입니다.
내가 보낸 요청 수정 불가수신기관의 회신이 이미 등록되어 원문이 잠겼을 가능성이 큽니다.
협의사항 원문 수정 불가답변이 달린 원문은 잠깁니다.
실증 인원 수정 불가해당 실증기관의 책임기관이 자기 기관인지 확인하십시오.
완료 인원 저장 오류입력 인원이 목표 인원보다 큰지 확인하십시오.
